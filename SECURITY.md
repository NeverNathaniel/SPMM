# Security Policy

## Reporting a vulnerability

Please report vulnerabilities **privately** via GitHub Security Advisories: open the repository's **Security** tab and choose **Report a vulnerability** (https://github.com/NeverNathaniel/SPMM/security/advisories/new).

Do **not** open public issues for security reports.

## Supported versions

Only the [latest release](https://github.com/NeverNathaniel/SPMM/releases/latest) is supported with security fixes.
